# ⚡ Nonsense Chat — Официальный ПК-клиент для Windows (Discord-архитектура)

Полноценный, высокопроизводительный десктопный клиент для Windows на базе архитектуры **Discord (Electron 33 + Node.js 26 + Chromium + WebRTC + аппаратное ускорение DirectX)**.

**Никаких урезанных имитаций, сторонних заглушек или фейковых версий — под капотом работает настоящий, аутентичный Nonsense Chat с полной поддержкой всех функций веб-платформы.**

---

## 🌟 Возможности клиента под капотом (как в Discord)

### 1. 🪟 Оконный интерфейс и фреймворк окна (Discord-Style Frameless Titlebar)
- **Кастомный заголовок окна**: Интегрированная безрамочная панель с нативными кнопками управления Windows 10/11 (свернуть, развернуть, закрыть).
- **Плавное перетаскивание**: Вся верхняя панель служит областью перетаскивания окна (`-webkit-app-region: drag`), при этом все кнопки, поиск и контролы остаются интерактивными.
- **Двойной клик по панели**: Мгновенно разворачивает или восстанавливает окно.
- **Запоминание геометрии**: Клиент сохраняет точные координаты (X, Y), размеры (Ширина, Высота) и состояние максимизации на правильном мониторе (`window-state.json`).
- **Защита от дублей (Single Instance Lock)**: При повторном запуске приложение не плодит копии в процессах, а мгновенно восстанавливает и фокусирует уже запущенное окно.

### 2. 🎨 Темы оформления — точно как на сайте
Клиент поддерживает все **4 официальные темы сайта** с динамической синхронизацией:
1. **Тёмная (стандарт)** — `#0f1923`, акценты `#5b8fb9`, текст `#e8f0f9`
2. **Кофейная тёмная** — `#1a0e06`, акценты `#c8906a`, текст `#f0e0cc`
3. **Кофейная светлая** — `#f5f0eb`, акценты `#9b6b3a`, текст `#2c1f14`
4. **Моховая тёмная** — `#0e1611`, акценты `#6b9e5f`, текст `#e6f0e4`

> При смене темы внутри мессенджера (или на старте) клиент в реальном времени обновляет цвет нативной панели Windows (`titleBarOverlay`), фоновый цвет окна и верхнюю панель заголовка.

### 3. 📌 Системный трей Windows (Discord Background Behavior)
- **Сворачивание в трей при закрытии**: Нажатие на крестик «✕» не убивает приложение, а мягко скрывает его в системный трей — вы не пропустите входящие звонки и сообщения.
- **Один или два клика по иконке в трее**: Мгновенно восстанавливают и фокусируют приложение.
- **Контекстное меню в трее**:
  - *Открыть Nonsense Chat*
  - *Свернуть в трей*
  - *Без звука уведомлений* (тихий режим)
  - *Запускать при старте Windows* (автозагрузка)
  - *Очистить кэш и перезагрузить*
  - *Перезагрузить приложение*
  - *Выйти из Nonsense Chat* (полное завершение)

### 4. 🔔 Нативные уведомления Windows Action Center
- Всплывающие карточки Action Center с аватаром чата, именем отправителя и текстом сообщения.
- Клик по уведомлению автоматически открывает клиент и переходит прямо в нужный диалог.
- Мигание иконки в панели задач (`flashFrame`), если приложение не в фокусе.
- Счётчик непрочитанных сообщений в подсказке трея и оверлее иконки на панели задач.

### 5. 🎙️ Звонки, видео и демонстрация экрана (Discord Screen Share)
- Аппаратное ускорение видеопотоков через Direct3D / GPU.
- **Демонстрация экрана (`desktopCapturer`)**: Захват экрана и окон без ограничений браузера.
- Подавление шума и эхоподавление в WebRTC.
- Автоматическая выдача нативных разрешений на микрофон, камеру, захват экрана и буфер обмена.

### 6. ⌨️ Горячие клавиши (Discord Shortcuts)
- `F11`: Переключение полноэкранного режима
- `F12` / `Ctrl + Shift + I`: Консоль разработчика (DevTools)
- `F5` / `Ctrl + R`: Перезагрузка интерфейса
- `Ctrl + Plus` / `Ctrl + Minus` / `Ctrl + 0`: Масштабирование (Zoom)
- `Esc`: Закрытие модальных окон, просмотрщика фото/видео, поиска
- `Ctrl + W`: Быстрое сворачивание в системный трей
- `Ctrl + Q`: Полный выход из приложения

### 7. 🔗 Глубокие ссылки (Deep Linking)
- Регистрация системного протокола `nonsense://` в Windows.
- Ссылки вида `nonsense://chat/<chatId>` автоматически открывают нужный чат прямо в десктопном клиенте.

### 8. 📋 Контекстное меню и проверка правописания
- Полноценное контекстное меню правой кнопки мыши: Отменить, Повторить, Вырезать, Копировать, Вставить, Выделить всё.
- Проверка орфографии на русском и английском языках (`ru-RU`, `en-US`).
- Для ссылок: «Открыть ссылку в браузере», «Скопировать адрес ссылки».
- Для картинок: «Копировать изображение», «Открыть в браузере».
- Внешние ссылки открываются в вашем системном браузере по умолчанию.

## 🚀 Запуск и сборка

### Быстрый запуск
В корне репозитория запустите любой удобный батник:
```cmd
run-pc.bat
```
*(Или `run-nonsense-chat.bat` / `start-desktop.bat`)*

### Сборка автономного `.exe`
```cmd
build-pc.bat
```
*(Или `build-desktop-exe.bat`)*

Готовый исполняемый файл будет доступен в:
`electron-desktop/dist/Nonsense Chat-win32-x64/Nonsense Chat.exe`
