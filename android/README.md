# 📱 Беспонтовый Чат — Native Android (Java)

Нативный Android-порт на **чистой Java** с оптимизированным UI, в точности повторяющим дизайн и кибер-эстетику веб-версии.

---

## 🎨 Дизайн и Оптимизации

- **Фирменная цветовая палитра**: глубокий обсидиановый фон (`#080C14`), неоновый изумрудный акцент (`#00FF88`), электрический циан (`#00D2FF`) и индиго (`#6366F1`).
- **Сверхбыстрый скролл**: оптимизированные `RecyclerView` с эффективной перерисовкой элементов (ViewHolder) и кэшированием для поддержки 60 / 120 FPS.
- **Telegram-Style Спойлеры**: кастомный компонент `TelegramSpoilerView` с процедурной анимацией мерцающей звездной пыли и плавным раскрытием по тапу с виброоткликом (Haptic).
- **Интерактивные опросы**: поддержка многовариантных и анонимных голосований с живым обновлением процентов и подсчетом голосов.
- **Индикатор набора текста**: живая синхронизация статуса "печатает..." в заголовке чата с 4.5-секундным TTL.
- **Генерация аватарок**: кастомный `AvatarView` с яркими гармоничными градиентами, инициалами и зеленым бейджем онлайна.

## 🏗 Архитектура

```
com.nonsensechat.app/
├── App.java                     // Инициализация Firebase, форсирование темной темы
├── data/
│   └── FirebaseManager.java     // Singleton Firebase Auth & RTDB, Presence, отправка сообщений
├── model/
│   ├── User.java                // Профиль пользователя, никнейм, онлайн, статус
│   ├── Chat.java                // Диалоги, группы, каналы, счетчики
│   ├── Message.java             // Текст, медиа, спойлеры, опросы, статусы
│   ├── Poll.java                // Опросы, подсчет голосов
│   └── PollOption.java          // Варианты ответов, проценты
├── ui/
│   ├── SplashActivity.java      // Мгновенный сплэш-экран и роутинг
│   ├── auth/AuthActivity.java   // Вход, регистрация, быстрый гостевой вход
│   ├── main/
│   │   ├── MainActivity.java    // Список чатов, вкладки (Все/Личные/Группы), поиск
│   │   └── ChatListAdapter.java // Адаптер списка чатов
│   ├── chat/
│   │   ├── ChatActivity.java    // Экран переписки, отправка, опросы, спойлеры
│   │   └── MessageAdapter.java  // Адаптер сообщений (текст, картинки, опросы)
│   └── custom/
│       ├── TelegramSpoilerView.java // Canvas-спойлеры в стиле Telegram
│       └── AvatarView.java          // Кастомные аватары с инициалами и статусом
```

## 🚀 Запуск и Сборка

### В Android Studio
1. Откройте Android Studio.
2. Выберите **Open** -> папка `d:\messenger\android`.
3. Дождитесь автоматической синхронизации Gradle.
4. Запустите на устройстве или эмуляторе (▶️ **Run 'app'**).

### Сборка через командную строку
```cmd
cd android

:: Сборка Debug APK
gradlew.bat assembleDebug

:: Готовый APK появится в:
:: app/build/outputs/apk/debug/app-debug.apk
```
